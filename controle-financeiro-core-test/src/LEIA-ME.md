# src/

Este projeto (`controle-financeiro-core-test`) existe exclusivamente para
hospedar os testes JUnit do projeto `controle-financeiro-core`. Por isso,
a pasta "Source Packages" (`src/`) não contém classes de produção — todo o
código de teste está na pasta "Test Packages" (`test/`).

Esta pasta precisa existir (mesmo vazia, além deste arquivo) para o
NetBeans reconhecer corretamente o projeto Java.
